1. 简介与定位

1. Introduction and Positioning

PreMap 是一个面向二倍体李属（Prunus）全同胞家系的数据处理与基因型清洗软件，提供从 VCF/Excel 到“数据集分类清洗过滤 → 连锁相位自动校正 → 重组断点识别 → Bin 划分错误校正与缺失基因型补充 → Bin 信息汇总”的端到端流程；它能够接受符合二等位表达与编码模式的任意类型标记，输出结果可直接用于主流图谱计算软件，且结果稳定，其作用不止用于连锁图谱的构建。

PreMap is a data processing and genotype cleaning software for diploid Prunus full-sib families. It provides an end-to-end workflow from VCF/Excel to “dataset classification, cleaning, and filtering → automatic linkage phase correction → recombination breakpoint identification → bin error correction and missing genotype imputation → bin information summarization.” It accepts any marker type following a biallelic expression/coding scheme. Outputs are directly compatible with mainstream mapping software and are useful beyond linkage-map construction.

  • 输入：VCF 4.2+（SNP/INDEL 等二等位位点）、按染色体拆分的 Excel 矩阵。
  • Input: VCF 4.2+ (SNP/INDEL and other biallelic sites), Excel matrices split by chromosome.
  • 输出：分离型位点矩阵、相位统一矩阵、重组断点与 bins、onebins、附加统计报表与图形。
  • Output: Segregating-loci matrix, phased matrix, recombination breakpoints and bins, onebins, plus additional statistical reports and figures.
  • 平台：Linux 与 Windows。
  • Platform: Linux and Windows.
  • 许可：非商业学术与育种研究免费使用；详见“许可证”。
  • License: Free for non-commercial academic and breeding research; see “License”.

1.1 软件简介

1.1 Software Introduction

核心定位：将高通量变异表（VCF）或自备标记信息，转换为生物学可解释且下游友好的基因型矩阵。

Core positioning: Transform high-throughput variant tables (VCF) or custom marker data into biologically interpretable, downstream-friendly genotype matrices.

处理路径：A/H/B 编码 → 规则化清洗 → 相位校正 → 识别重组 → 最小重组单位划定 → bin marker 校正与填充 → 生成 onebins 矩阵。

Processing path: A/H/B coding → rule-based cleaning → phase correction → recombination detection → delineation of minimal recombination units → bin-marker correction and imputation → generation of the onebins matrix.

模块一览

Module overview

  • Step0 / Step0_Indel：VCF 规范化与拆分，生成转码后的标记矩阵并按染色体以 Excel 保存。
  • Step0 / Step0_Indel: Normalize and split VCF; produce recoded marker matrices and save per chromosome in Excel.
  • Step0_5：为每个位点计算 A/H/B/缺失 计数与基因型频率。
  • Step0_5: Compute A/H/B/missing counts and genotype frequencies for each locus.
  • Step1：按缺失、错误率与频率阈值清洗；以伪测交策略逐步划分 1:1、1:2:1、Parent1/Parent2 标记矩阵。
  • Step1: Clean by missingness, error rate, and frequency thresholds; using a pseudo-testcross strategy, progressively derive 1:1, 1:2:1, and Parent1/Parent2 matrices.
  • Step2：基于相似性阈值的相位调整与聚类清洗；进行连锁相位校正与 IBD 片段识别。
  • Step2: Similarity-threshold-based phase adjustment and cluster cleaning; linkage-phase correction and IBD fragment identification.
  • Step3：Binning——个体水平的重组断点识别。
  • Step3: Binning — individual-level recombination breakpoint identification.
  • Step4：OneBins——群体水平最小重组单位与 bin marker 鉴定；轻度纠错与缺失填补；记录修改历史。
  • Step4: OneBins — population-level minimal recombination unit and bin-marker identification; mild correction and imputation; full change logging.
  • Step-Addition：附加统计（测序专用），按修改事件高低筛查可能未成功杂交/污染个体。
  • Step-Addition: Additional statistics (sequencing only) to flag potential non-hybrid/contaminated individuals by modification-event burden.

1.3 功能亮点与适用边界

1.3 Features & Scope

亮点

Highlights

  • 双通道输入：SNP 与 INDEL（及符合二等位表达与编码模式的任意标记）。
  • Dual input channels: SNP and INDEL (and any biallelic markers following the coding scheme).
  • 可视化友好：按染色体拆分的 Excel、GUI 操作、下划线断点标注。
  • Visualization-friendly: per-chromosome Excel, GUI operations, and underline markers for breakpoints.
  • 相位与聚类：s/l/m 三阈值控制，稳健相位矫正及 IBD 识别。
  • Phasing & clustering: s/l/m triple-threshold control, robust phase correction and IBD detection.
  • 可追溯性：重组断点划分、标记修正与补缺全过程留痕。
  • Traceability: full audit trail for breakpoint partitioning, correction, and imputation.
  • 附加统计：快速圈定异常个体（潜在未成功杂交/污染）。
  • Additional stats: quickly narrow down abnormal individuals (potential non-hybrids/contaminants).

边界

Boundaries

  • 主要适用对象：二倍体 & 全同胞家系；多倍体/复杂群体未验证。
  • Primary scope: diploids & full-sib families; polyploids/complex populations are unvalidated.
  • 不负责变异检测（VCF 由外部流程产出）。
  • Variant calling is out of scope (VCFs come from external pipelines).
  • Step0 仅支持 Linux（因数据量与内存需求）。
  • Step0 is Linux-only (due to data volume and memory requirements).
  • 建议结合生物学知识与实验记录进行复核。
  • Cross-check with biological knowledge and lab records is recommended.

4.2 常见坑与提示（Quick Tips）

4.2 Quick Tips

  • Windows GUI 若出现无法写入，建议重新安装 exe 并选择其他安装路径。
  • If the Windows GUI cannot write files, reinstall the exe and choose a different install path.
  • Step1 表头区分大小写；若缺少统计列请先运行 Step0_5。
  • Step1 headers are case-sensitive; if statistics columns are missing, run Step0_5 first.
  • Step2 的 s/l/m：不确定时可从 s≈0.90，l≈0.01–0.02，m≈0.10 起步，再结合 Reoriented_Clusters 调整。
  • For Step2 thresholds s/l/m: start with s≈0.90, l≈0.01–0.02, m≈0.10, then refine using Reoriented_Clusters.
  • Step3 若人工调整 bins，务必同步维护 bins-record。
  • If you manually edit bins in Step3, keep bins-record in sync.
  • 测序数据质量建议：平均覆盖度 ≥15× 更稳健；低于此值请谨慎放宽缺失与错误率阈值。
  • Sequencing data quality: mean depth ≥15× is more robust; if lower, be cautious when relaxing missing/error-rate thresholds.

5.2 亲本与群体命名（Parents & Population Naming）

5.2 Parents & Population Naming

  • 群体/染色体命名示例：Pp01、Pp02…（与参考基因组一致）。
  • Sample order: Female in column 1, Male in column 2; followed by progeny Individual1….
  • Population/chromosome naming examples: Pp01, Pp02, … (consistent with the reference genome).

5.3 染色体与坐标规范（Chromosome & Coordinates）

5.3 Chromosomes & Coordinates

  • 示例使用 Lovell v2.0 等标准装配；POS-2 表示染色体内物理位置。
  • 以分析中使用的参考基因组为准，无需统一到单一版本。
  • Examples use standard assemblies such as Lovell v2.0; POS-2 denotes the physical position on the chromosome.
  • Use the reference genome version applied in your analysis; unification to a single version is not required.

5.4 文件与字段命名规则（File & Header Naming Rules）

5.4 File & Header Naming Rules

  • Step1 输入前 5 列表头（区分大小写）：Number, CHR, POS-2, Female, Male。
  • Step0_5 会追加：A_Count, H_Count, B_Count, -_Count, f(A), f(H)。
  • 工作表命名：step1、Parent1、Parent2、bins、bins-record、onebins… 请勿改名。
  • 输出文件命名：{input}_phased.xlsx、{input}_bins.xlsx、{input}_onebins.xlsx、{input}__processed.xlsx 等；如需自定义可在命令中添加参数。
  • First 5 header columns for Step1 input (case-sensitive): Number, CHR, POS-2, Female, Male.
  • Step0_5 appends: A_Count, H_Count, B_Count, -_Count, f(A), f(H).
  • Worksheet names: step1, Parent1, Parent2, bins, bins-record, onebins. Do not rename.
  • Output filenames: {input}_phased.xlsx, {input}_bins.xlsx, {input}_onebins.xlsx, {input}__processed.xlsx. Add CLI parameters if you need custom names.

使用建议 / Practical guidance

Practical Guidance

s（similarity_threshold）
s (similarity_threshold)
S_max ≈ 1 - (r + e) / N

N：子代数；r：真实重组引起的不一致（常 1–2）；e：测序/识别误差（~1% @15×）。如 N=150, r=2, e=2 → S_max≈0.9733。建议数据较好时 s≥0.90；不建议低于 0.80。

N: number of progeny; r: true recombination-induced disagreements (often 1–2); e: sequencing/calling error (~1% @15×). Example: N=150, r=2, e=2 → S_max≈0.9733. For good data, s≥0.90 is recommended; not advised to go below 0.80.

l 与 m
l and m
  • 起步可用 l=0.01–0.02，m=0.10；
  • 高 s 时易产生小碎簇：降低 l 可避免误删；设中等 m 标成灰区以便复核。
  • Start with l=0.01–0.02, m=0.10;
  • High s tends to produce tiny clusters: lower l to avoid over-deletion; use a moderate m to flag gray-zone clusters for review.
复核与微调
Review & Fine-tuning
  • 在 Reoriented_Clusters 看趋势：若灰区小簇与前后主簇一致，可调低 s 或提高 m 并在 Marked_Results 改判为保留。
  • 碎簇过多：升高 l 或略降 s；过度合并：升高 s、下调 m。
  • Check trends in Reoriented_Clusters: if a gray-zone micro-cluster matches adjacent main clusters, lower s or raise m and re-mark to keep it in Marked_Results.
  • Too many micro-clusters: increase l or slightly decrease s; over-merging: increase s and lower m.

13. Step-Addition — Additional Calculation（测序数据专用）

13. Step-Addition — Additional Calculation (Sequencing Data Only)

13.1 模块说明

13.1 Module Description

本模块用于在 Step2（Phasing）之后对矩阵做基于错误的统计筛查，帮助识别可能未成功杂交/混样/污染的个体。核心假设：若某个个体并未按预期与另一亲本杂交，则其基因型模式将长期更接近某一亲本，在按统一规则进行 impute/correct 时会产生显著更多的修改条目。

仅支持测序数据；标记越多效果越好。对芯片等小数据集更建议人工核查与实验对照，因此不提供 Windows 版本。

建议输入：Step2 的 Cleaned_Results 或你确认过的单一矩阵（见图 13-1）。

This module performs error-based statistical screening after Step2 (Phasing) to help identify individuals potentially resulting from failed crosses, sample mix-ups, or contamination. Core assumption: if an individual did not originate from the expected cross, its genotype pattern tends to resemble one parent; under unified imputation/correction rules, it will trigger noticeably more modification events.

Supported for sequencing data only; the more markers, the better. For small chip datasets, manual inspection and experimental validation are preferred, so no Windows version is provided.

Recommended input: Step2’s Cleaned_Results or a vetted single matrix (see Fig. 13-1).

13.5 判读与建议

13.5 Interpretation & Tips

  • 只做统计，不改真值：小写 a/h 是“算法判为更合理的状态”的可视化标记，并不替换真实基因型；最终分析请继续沿用 Step2/Step4 的结果表。
  • 阈值选择：
    • 若散点图头部个体过多，尝试减小 -d（更严格，拆分长事件）；
    • 若同一问题个体在多条染色体上都异常偏高，则高度可疑。
  • 并行：--n_jobs 默认为全部核心；如与其他任务共享机器，可手动下调。
  • 复核清单：建议对每条染色体与全基因组分别统计，关注 Modification statistic 排名前 1–5% 的个体，并在 Modifications Summary 2 中查看其典型区段长度是否异常长。
  • Statistics only, no change to truth: lowercase a/h are visual tags for “algorithm-suggested” states; final analyses should continue to use Step2/Step4 result sheets.
  • Threshold tuning:
    • If too many individuals cluster at the top of the plot, try lowering -d (stricter; splits long events).
    • Individuals consistently high across multiple chromosomes are highly suspicious.
  • Parallelism: --n_jobs defaults to all cores; reduce it if sharing the machine.
  • Review checklist: compute per-chromosome and genome-wide stats; focus on the top 1–5% in Modification statistic, and check whether their typical spans are unusually long in Modifications Summary 2.

14. 术语表（Glossary）

14. Glossary

  • A/H/B 编码（A=ref/ref，H=ref/alt，B=alt/alt）：统一的基因型表示法。 A/H/B coding (A=ref/ref, H=ref/alt, B=alt/alt): unified genotype notation.
  • Segregating loci（分离位点）：通过 Step1 过滤后仍保持多态的位点集合。 Segregating loci: set of polymorphic sites remaining after Step1 filtering.
  • 1:1 / 1:2:1：理论分离比；分别对应 CP 群体中不同亲本杂合情形。 1:1 / 1:2:1: theoretical segregation ratios for different parental heterozygosity patterns in CP populations.
  • Parent1 / Parent2：母本杂合 / 父本杂合的两个矩阵（Step1 输出）。 Parent1 / Parent2: matrices for maternal-heterozygous / paternal-heterozygous markers (Step1 output).
  • Phase（相位）：等位基因在染色体上的方向；Step2 统一簇内相位方向。 Phase: allele orientation along the chromosome; Step2 unifies orientations within clusters.
  • Cluster（簇）：按位点间相似度归并的集合；阈值 s 控制切割粒度。 Cluster: grouping of sites by similarity; threshold s controls granularity.
  • l / m：小簇直接删除阈值 / 灰区簇待判阈值。 l / m: thresholds for deleting tiny clusters / flagging mid-frequency “gray-area” clusters.
  • Reoriented_Clusters：对所有簇做全局方向重排的矩阵。 Reoriented_Clusters: matrix after globally reorienting all clusters.
  • Marked_Results：删除低频小簇，并标注灰区簇及邻域相似度指标的矩阵。 Marked_Results: matrix with low-frequency tiny clusters removed and gray clusters annotated with neighborhood similarity metrics.
  • Cleaned_Results：Step2 的最终清理矩阵。 Cleaned_Results: final cleaned matrix from Step2.
  • Breakpoint（断点）：个体染色体上重组发生的位置；Step3 用下划线标注。 Breakpoint: location of recombination on an individual’s chromosome; underlined in Step3.
  • bins：按断点划分出的连续同向片段。 bins: contiguous segments with consistent trend defined by breakpoints.
  • bins-record：断点审计表，记录位置、范围、受影响个体等。 bins-record: breakpoint audit log including positions, ranges, and affected individuals.
  • onebins：Step4 将每个 bin 汇总为 1 行的代表性标记矩阵。 onebins: representative-marker matrix with one row per bin produced in Step4.
  • bins_correction：onebin 生成过程的修改历史（首位点校正，小写字母标识）。 bins_correction: edit history during onebin generation (first-site corrections shown in lowercase).
  • Step-Addition：仅测序数据使用的附加统计模块，用修改事件数量筛查异常个体。 Step-Addition: sequencing-only auxiliary statistics module to flag anomalous individuals by modification event counts.
  • MAF：次要等位基因频率；常用于早期过滤。 MAF: minor allele frequency; commonly used for early filtering.
  • POS-2：染色体内的物理位置列（按参考基因组坐标，如 Lovell v2.0）。 POS-2: physical position within a chromosome (reference coordinates, e.g., Lovell v2.0).
  • 缺失符号 -：无有效基因型的占位符。 Missing symbol -: placeholder for missing genotype calls.
